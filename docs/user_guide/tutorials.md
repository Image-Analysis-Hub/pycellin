# Tutorials

Until this guide is complete, these notebooks show how to use Pycellin. Read them in this order:

| Notebook | Description | Level |
| --- | --- | --- |
| {repo}`Getting started <notebooks/Getting%20started.ipynb>` | The basics of Pycellin, through examples | Beginner |
| {repo}`Managing properties <notebooks/Managing%20properties.ipynb>` | How to add, compute and remove properties | Beginner |
| {repo}`Custom properties <notebooks/Custom%20properties.ipynb>` | How to create user-defined properties and add them to your lineages | Advanced |

GitHub shows these notebooks without their figures, which only appear when you run them. To run them, install Pycellin with the example notebooks (step 4 of [](installation.md)) and download the [repository](https://github.com/Image-Analysis-Hub/pycellin): the notebooks read the files of its `sample_data` folder.
